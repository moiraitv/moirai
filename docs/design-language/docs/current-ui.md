# Current UI baseline and shared-style unifications

[Handbook](../README.md) · [Layout recipes](layouts.md)

The running application’s Vue components and feature styles define the baseline. This guide documents
those patterns and consolidates shared styling; it does not authorize replacing accepted page layouts
or workflows. The local gallery is a source-shaped, fixture-driven reference, not the running Vue app.

## Consolidate inconsistencies without redesigning

| Area                     | Observed source                                                                                                             | Shared reference decision                                                                                                                                                                                                                                       |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Title / subtitle spacing | Page headers, editor headings and Settings title rows use different margins; help-button height can inflate the visible gap | One 2px gap token for supporting text; 24px visual help glyph frame with an expanded 44px pointer target, so the title row does not acquire empty height                                                                                                        |
| Desktop shell            | App.vue / foundation: 244px rail; 28px vertical page inset and clamp(24px, 2.6vw, 42px) inline inset                        | Preserve these dimensions and the current grouped navigation / logo                                                                                                                                                                                             |
| Program layout           | 80px minimum rows; 390px inline inspector; explicit compact-column rules                                                    | Preserve list columns and separate editor navigation; remove the invented Duration column and catalog pagination                                                                                                                                                |
| Resource editor          | 820px dialog; Number / Name / Group; logo and feature-owned sections                                                        | Preserve field ownership and footer Save/Close semantics; no invented Guide title or Description fields                                                                                                                                                         |
| Two-step armed geometry  | Current TwoStepActionButton swaps its content, which can change the footprint                                               | Keep the original content in flow while centering the armed checkmark over it; optional confirmation text must fit without changing the original size, shape or position                                                                                        |
| Control heights          | Common button 42px, some selects 43px and contextual actions around 32–34px                                                 | Use 42px normal / 32px compact / 44px touch as shared sizes, with component-specific exceptions documented                                                                                                                                                      |
| Corners                  | Existing values include 5, 7, 8, 9, 10, 12 and 13px                                                                         | Normalize the documented scale to 4 / 8 / 12 / 16px; keep the reversible 50% trial at 2 / 4 / 6 / 8px active                                                                                                                                                    |
| Semantic palette         | Current navy canvas/panels, mint and secondary text                                                                         | Preserve the identity. Retain previously reviewed subtle surface and field gradients, dark-on-mint actions and stronger essential boundaries as explicit style unifications, not observed pixel values                                                          |
| Icons and view choices   | Lucide; some utility frames differ                                                                                          | Retain reviewed bezel-free utility and section icons; use the connected segmented control for peer view choices. Prominent primary and destructive actions gain a leading semantic icon; secondary and subdued actions stay text-only, as documented in Actions |
| Settings                 | Playback / AI / Backups, tab-owned drafts, saved-value disclosures and one footer per tab                                   | Keep these current ownership boundaries and tabs; tighten headings without restructuring the forms                                                                                                                                                              |

Named radii in component tables are the normalized **baseline**, not the currently active experimental
values. The trial stylesheet still halves that scale and has a one-link revert. No production styles,
APIs, database values or user-guide review digests are changed by this work.

## Adding or revising a pattern

Start with its owning current component. Preserve its task, controls, vocabulary, data ownership and
navigation. Record a specific inconsistency before choosing one shared value. Add or update the
specimen, current-source mapping and associated captures together. Treat larger layout / behavior
changes as separate proposals. Earlier AI concepts are historical exploration and cannot override
these current-source contracts.

Page help follows `PageHeader.vue`, `PageHelpButton.vue` and their source topic mappings: Programs, Libraries, Channel Schedules and channel editors retain title-adjacent question-mark controls. Settings uses section-level help only. Reference help uses copied bundled topic HTML and chapter snapshots with unchanged review state. See the complete [audit](audit.md) for corrected source contracts.
