## Presentation corrections after review

The first audit missed presentation regressions. Status navigation now keeps its complete height,
small mint summaries and normal icon; Quick Setup has spacer gaps without dividers. The account
footer has its own full-width rule, flexible text column and correctly aligned chevron/sign-out.
Library Sort by uses the same structural border as its neighboring tools. Channel editors restore
framed fieldsets, the original logo-picker panel, compact policy cards, and the icon/title/subtitle/
chevron disclosure anatomy. Settings retains plain heading icons; channel disclosure icons keep their
source-owned circular frames. Status and Logs now have separate full-page references.

The compact Guide feed buttons and floating Engine details panel are explicit user-requested
revisions to the source presentation. Guide cards preserve the media artwork wash with its source
brightness, opacity and fade treatment. [Engine popup](../images/layouts/settings-engine-open.png).

## Evidence and boundaries

The isolated source capture uses the real built application, documentation seed and a disposable
server/database. Its fixed January fixture date, administrator identity, loopback-URL warning,
backend readiness, library names/counts and source media durations can differ from the local
October reference fixture. Those are data/environment variants, not replacement workflows.
No source screenshots are published into the user guide or marked reviewed.

The local reference has native modal/popover containment rather than importing the production Vue
runtime. It does not reproduce virtualization, schedule resolution, network services or backend
validation. Where a static sample retains an operation control (scan/sync, file crop, AI generation,
provider verification, backup/restore, source-browser queries, refresh or full log streaming), the
application owner remains authoritative and no successful result is invented. File pickers, native
fields and presentation-only dialogs do not perform those operations. Complete application routes
outside the representative layouts lead to local reference guidance; `data-app-path` records their
actual destination. Content/Similar Items/Theme editing and new-Program creation lead to their focused specimens;
only the represented Sequence has a complete local editor. Guide media-detail links lead to the
media specification. These keep their actual resource route annotations and do not misroute to
an unrelated editor or library page. Account/sign-out are presentation only. These are prototype limits, not proposed
changes to Moirai.

## Help content boundary

`assets/help` is a self-contained copy of the existing bundled contextual-help HTML, artwork and
chapter snapshots. Topic IDs, descriptions and review warnings are preserved; the extraction command
reads an existing documentation build and never publishes or approves it. Source screenshots inside
those chapters retain their original app appearance and do not override the approved guide finish.

## Final consistency corrections

The AI provider card integrates its independent enable switch and advanced-disclosure handle into one header. Its divider stays visible in both states, the title also toggles optional fields, and basic provider/key fields stay visible. Engine details dismisses when scrolling moves its anchor, or on resize; queued scroll events with unchanged anchor geometry do not close a newly opened popup.

Keep Filler after Libraries and retain a 16px bottom navigation gutter above User Guide. Library alphabet and sort controls share their outer height, including the letter strip’s borders and coarse-pointer targets. Compact Library editor checkbox stacks retain adjacent rows rather than stretching their gap. Exact source-owned checkbox/switch geometry and touch hit rows are documented in [choices](../components/choices.md).

The final audit also corrected guide tests for the integrated AI header and locally scoped catalog sizing. Current verification totals and limitations belong to [application adoption](application-adoption.md), rather than older capture-pass statistics.
