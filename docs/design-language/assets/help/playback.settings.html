Settings

The Settings guide now has a dedicated page for each tab:

  • Playback settings: stream capacity, filler, viewing preferences, and playback status.
  • AI settings: providers, credentials, models, and web research.
  • Backup settings: automatic backups and saved configuration archives.

Use the question-mark button beside a card heading in Settings to open help for that section. Open full guide opens the corresponding section in this guide.
