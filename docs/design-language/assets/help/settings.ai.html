AI settings

Open Settings → AI to connect a provider.

AI provider

On the AI tab, in AI provider, choose a provider and enter its API key. The recommended model is used by default, but the header disclosure allows you to set a different model, enable web research functionality, and choose its time limit. Choose Custom to enter your own endpoint and format. Use the handle at the right edge of the AI provider header, or select its title, to expand or collapse advanced fields without losing your unsaved values. Provider and API Key remain visible.

Saving AI credentials runs a one-time check on the connection. The Enable AI switch beside the heading turns AI off while retaining saved credentials, or reconnects the selected saved provider. Save or reset pending provider changes before turning AI back on. The switch shows the saved state if the request fails. See AI content selection for more details.

Forget key permanently removes the selected provider’s saved credential, and you must enter a replacement key to use that provider again. Backup archives include AI preferences but exclude API keys, so enter credentials again after restoring.
