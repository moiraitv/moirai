# AI settings

Open **Settings → AI** to connect a provider.

## AI provider {#ai-provider}

On the **AI** tab, in **AI provider**, choose a provider and enter its API key. The recommended model is used by default, but **Advanced** allows you to set a different model, enable web research functionality, and choose its time limit. Choose **Custom** to enter your own endpoint and format. 

Saving AI credentials runs a one-time check on the connection. **Disable AI** turns AI functionality off (this retains saved credentials), and **Enable AI** can reconnect the selected saved provider. See [AI content selection](/operations/configuration) for more details.

**Forget key** permanently removes the selected provider’s saved credential, and you must enter a replacement key to use that provider again. Backup archives include AI preferences but exclude API keys, so enter credentials again after restoring.
