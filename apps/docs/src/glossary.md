# Glossary

**Channel** — A numbered stream with a name, playback profile, and schedule.

**Committed guide** — The future lineup Moirai has accepted for delivery. It can differ from an
unsaved preview.

**Dead air** — Time for which scheduling did not produce primary media. Playback uses fallback filler
so the stream remains valid.

**EPG / XMLTV** — The program-listing data an IPTV application displays as a guide.

**Filler** — Media allowed to occupy unused time around scheduled programs.

**Library** — A configured media folder and Moirai's searchable index of its contents.

**M3U** — The playlist file that tells an IPTV client which channels exist and where to stream them.

**NFO** — A sidecar text file, commonly produced for Kodi, containing titles, plots, genres, credits,
and other media details.

**Program** — A reusable choice of eligible media plus an ordering rule.

**Template** — A reusable arrangement of programs into parts of a nominal day.

**Channel schedule** — The base template and conditional layers assigned to one channel.

**Transcoding / normalization** — Converting source media into a consistent live-stream format that
IPTV clients can play.
