# Templates

A template divides a nominal day into slots. Each slot starts at an authored time and normally uses
one program. Channel schedules can reuse the same template on many dates or layers.

![The templates catalog](/screenshots/templates.png)

Real media rarely ends exactly on a slot boundary. A slot therefore needs a boundary decision: allow
the current item to finish, cut at the boundary, or apply the configured alignment behavior. Filler
can occupy remaining time when the primary program cannot.

Use the resolved preview to see actual start and finish times rather than relying only on the authored
grid. Warnings call out missing media, invalid durations, and gaps that would otherwise become dead
air.

Keep templates focused on a reusable daily structure. Date-specific choices belong in channel
schedule layers rather than copies of nearly identical templates.
