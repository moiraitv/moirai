# Settings

Settings has separate tabs for Playback, Media Servers, AI, and Backups. Find help for each area below:

- [Playback settings](/settings/playback): stream capacity, filler, viewing preferences, and playback status.
- [Media Servers](#media-library-servers): shared Plex, Jellyfin, and Emby connections.
- [AI settings](/settings/ai): providers, credentials, models, and web research.
- [Backup settings](/settings/backups): automatic backups and saved configuration archives.

Use the question-mark button beside a card heading in Settings to open help for that section. **Open full guide** opens the corresponding section in this guide.

## Media library servers

Open **Settings → Media Servers**. Then choose **Add Media Server** to save a Plex, Jellyfin, or Emby connection. Use the **Server** and **Authentication** cards to enter its address and sign in. Jellyfin and Emby support username/password or an API key; Plex supports link-code sign-in or a token. **Test connection** verifies everything without saving it. Open **Advanced** for folder mappings, then save the connection. Use **Edit** to change shared settings or folder mappings, replace a credential, or delete an unused server. See [Libraries and scanning](/libraries/managing-libraries) for details.
