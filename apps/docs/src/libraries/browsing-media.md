# Browse and filter media

Open a library to browse its indexed catalog. Search narrows the current results by name. Sorting,
date windows, and filters help with larger collections.

![An indexed media library](/screenshots/library-catalog.png)

The filter editor can include or exclude genres and apply facts such as actors, directors, ratings,
and dates when those values exist in the source metadata. An empty result means nothing matches the
whole active filter; it does not mean the library is empty.

Open an item to inspect its artwork, plot, credits, source paths, subtitles, and technical playback
details. Missing information usually means it was absent from the NFO file or media probe.

![Indexed media details](/screenshots/media-item.png)

Selection mode lets you choose visible items or all items matching the current filter and add them to
an existing program. Check the displayed match count before adding a broad recursive selection.
